📋 Paste Your Data

Supports CSV, TSV, or semicolon-delimited. First row = headers. Copy directly from Excel or Google Sheets and paste below.

🔗 Fetch from URL

Enter a direct link to a public CSV file. Works with GitHub raw URLs, WHO datasets, and publicly shared Google Sheets (File → Share → Publish to web → CSV).
⚠️ URL must be publicly accessible. If blocked by CORS, download the file and use Paste instead.

🌍 World Bank Open Data

Free, live data from the World Bank API — no login required. Covers 200+ countries and thousands of indicators.
